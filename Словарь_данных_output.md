Для `output/master_dataset.csv` — отдельный документ `Словарь_данных_master_dataset.md`, для районного `master_dataset_districts.csv` — `Словарь_данных_master_dataset_districts.md`. Здесь описаны все прочие файлы пайплайна: промежуточные (сырые по каждому источнику) и производные (валидация, цены, спред, снимок, районный климат и почва, региональные цены). Файлы 01–10 актуальны на 2026-09-10, файлы 11–16 добавлены и описаны 2026-10-05.

**Скрипт:** `01_faostat.py`. **Строк:** 466. **Гранулярность:** (культура, показатель, год).

## 04_soilgrids_long.csv / 04_soilgrids_wide.csv — почва

**Скрипт:** `04_soilgrids.py`. Длинный формат: 640 строк (20 точек × 4 глубины × 8 свойств, полное покрытие). Широкий: 80 строк (точка × глубина).

**Про повтор при сбое:** SoilGrids REST API временами роняет отдельные запросы без системной причины (таймаут/5xx) — без повтора набор точек с данными был недетерминирован от запуска к запуску (обнаружено 2026-09-11: 17 из 20 точек в одном запуске, другие 17 — в следующем). `fetch_soilgrids_point()` теперь повторяет неудавшийся запрос до 3 раз с задержкой, кратной интервалу rate limit — с этим все 20 точек собираются стабильно.

| Столбец | Тип | Описание |
|---|---|---|
| `lat`, `lon` | float | Координаты точки сетки (шаг ~2°, зерновой пояс) |
| `depth` | str | `0-5cm`, `5-15cm`, `15-30cm`, `30-60cm` |
| `property` | str | Только в длинном формате: `phh2o`, `soc`, `bdod`, `clay`, `sand`, `silt`, `cec`, `nitrogen` |
| `value_raw` | float | Сырое целочисленное значение от API, ДО деления на `d_factor` |
| `value` | float | После деления на `d_factor` — физически корректное значение (см. Отчёт §2.4 про баг с `d_factor` vs `conversion_factor`) |
| `unit` | str | Единица от API (`pH*10`, `dg/kg` и т.д. — описывает МАСШТАБ сырого значения, не `value`) |
| `bdod` … `soc` | float | В широком формате — те же 8 свойств как отдельные столбцы, уже после конверсии. Единицы — см. `Словарь_данных_master_dataset.md`, раздел "Почва" |

## 11_price_index_raw.csv / 11_price_index_chained.csv — национальный индекс цен производителей

**Скрипт:** `11_price_index.py`. Источник: динамический ряд stat.gov.kz (элемент 1644), 1992–2025. Только национальный уровень и только товарные **группы** (нет отдельных индексов по пшенице, ячменю и т.д.).

`11_price_index_raw.csv` — 204 строки (34 года × 6 категорий), длинный формат, значения как в источнике:

| Столбец | Тип | Описание |
|---|---|---|
| `year` | int | Год, 1992–2025 |
| `category` | str | `agriculture_total`, `crop_production_total`, `grain_crops_group`, `oilseed_crops_group`, `potato`, `vegetables` |
