# Лицензия на данные (`output/*.csv`)

Собранные, очищенные и агрегированные данные в `output/` — само по себе
составительство (compilation): выбор источников, методы сбора, очистка
единиц измерения, объединение, производные признаки (лаги, скользящие
средние, спред) — лицензируются по **CC BY 4.0** (Creative Commons
Attribution 4.0 International).

Это означает: данные можно свободно использовать, распространять и
модифицировать, в том числе в коммерческих целях, при условии указания
авторства (Akezhan Kumarov, ссылка на этот репозиторий).

## ⚠️ Важно: лицензия на составительство НЕ отменяет условия первоисточников

Каждый первичный источник данных имеет собственные условия использования,
которые нужно соблюдать при цитировании/переиздании, независимо от
лицензии на итоговую компиляцию.

## Производные файлы, объединяющие несколько источников

`master_dataset.csv`, `master_dataset_districts.csv`, `master_dataset_districts_2022_2025.csv` — компиляции
нескольких источников (stat.gov.kz, FAOSTAT, World Bank, ERA5-Land, SoilGrids, OpenStreetMap). Для них
действует CC BY 4.0 на составительство, **и одновременно все условия первоисточников из таблицы выше**.
При использовании файла нужно указать атрибуцию каждого источника, чьи столбцы вы используете (см. словарь
данных `Словарь_данных_master_dataset_districts.md`, колонка «Источник/скрипт» в заголовках блоков). Если из
файла берётся только часть столбцов, обязательна атрибуция только соответствующих источников, кроме
координат (`lat`, `lon`) — там действует OSM-условие выше.

Файл `Словарь_данных_master_dataset_districts.md` и тесты `tests/` лицензируются так же, как код: MIT.

## Что не проверялось

Условия ERA5/Copernicus, World Bank и SoilGrids повторно не проверялись с 2026-09-14 (см. таблицу).
Условия stat.gov.kz для данных по ценам и условия OSM/Nominatim добавлены 2026-10-05 без повторного
открытия страниц сайтов. Перед публикацией новой версии на Zenodo эти пять источников стоит
подтвердить.

## Рекомендация для Data Descriptor

При подготовке статьи (см. обсуждение про Zenodo/DOI):
1. Связаться с grainunion.kz для подтверждения условий редистрибуции —
   единственный источник без формальной публичной политики.
2. Перед финальной подачей статьи стоит переподтвердить World Bank/
   Copernicus/SoilGrids (не проверялись повторно 2026-09-14) — условия
   у крупных международных источников меняются редко, но год-два назад
   FAOSTAT тоже сменил лицензию, так что разовая проверка перед сдачей
   не будет лишней.
3. В разделе "Usage Notes" статьи явно перечислить все первоисточники с
   их лицензиями (таблица выше — готовая основа, уже перенесена в
   черновик статьи).
4. Код (`*.py`) лицензирован отдельно — MIT, см. `LICENSE`.
